# EventBooster 🎫

A collaborative event discovery platform that helps users find and explore the best events around the world.

This project was developed during *GoIT course*, following provided design specifications in Figma.

## 🚀 Live Demo

[View Live Application](https://ellamm.github.io/EventBooster/)


## ✨ Features

- **Global Event Discovery**: Find events worldwide with comprehensive search
- **Advanced Filtering**: Filter by location, date, category, and price range
- **Event Details**: Comprehensive event information with venue details
- **Interactive Maps**: Location visualization for event venues
- **Responsive Design**: Seamless experience across all devices
- **User Favorites**: Save and manage favorite events
- **Real-time Updates**: Live event availability and pricing
- **Social Sharing**: Share events across social platforms
- **Modern UI/UX**: Clean, intuitive interface design

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **CSS Framework**: Modern CSS with Flexbox/Grid
- **API Integration**: RESTful API consumption
- **Build Tools**: Webpack/Parcel for bundling
- **Version Control**: Git
- **Deployment**: GitHub Pages

## 📈 Performance Optimizations

- **Lazy Loading**: Images and components load on demand
- **API Caching**: Intelligent caching for frequently accessed data
- **Code Splitting**: Optimized bundle sizes
- **Image Optimization**: WebP format with fallbacks
- **Minification**: Compressed CSS and JavaScript
